# Neburion XV73 Beta 2.1 – Exercise Runner 2.0 + Memory Lab

## Ziel

Dieser Sprint erweitert die App um eine zentrale Memory-Lab-Übungsfamilie und stärkt die gemeinsame Exercise-Runner-Architektur.

## Verbindlicher Gedächtnisablauf

1. Anzeigen
2. Definierte Merkzeit
3. Vollständiges Ausblenden
4. Abrufen ohne sichtbare Lösung
5. Feedback
6. Strategiehinweis
7. Nächste Aufgabe

Der Merkinhalt darf während der Antwortphase nicht mehr sichtbar sein.

## Memory-Lab-Kategorien

- Wörter
- Zahlen
- Symbole
- Reihenfolgen
- Geschichten

Jede Kategorie ist in fünf Stufen vorhanden:

- Einstieg
- Leicht
- Mittel
- Schwer
- Profi

## Exercise Runner 2.0

Unterstützte Aufgabentypen:

- single-choice
- multi-choice
- sequence
- memory-choice
- memory-recall
- memory-sequence

## Progress Engine 2.0

Gespeichert werden pro Aufgabe:

- Trainingsdomäne
- Kategorie
- Schwierigkeitsgrad
- Ergebnis
- Dauer
- Übungs-ID
- Übungstyp
- Zeitpunkt

Die Fortschrittsseite zeigt konkrete Tabellen nach Domäne und Gedächtniskategorie.

## Coach Feedback 2.0

Der Coach formuliert:

- empfohlener nächster Bereich
- aktuelle Durchschnittsleistung
- konkrete Strategie
- nachvollziehbarer Grund auf Basis gespeicherter Ergebnisse

Keine Diagnose, keine medizinische Bewertung und keine Heilversprechen.

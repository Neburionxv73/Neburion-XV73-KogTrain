NEBURION XV73 BETA 2.3 – LOKALE VORSCHAU

EMPFOHLENER START
1. ZIP vollständig entpacken.
2. Den entpackten Projektordner öffnen.
3. START_NEBURION_LOKALE_VORSCHAU.bat doppelklicken.
4. Beim ersten Start werden die benötigten Pakete installiert und der Build erstellt.
5. Danach öffnet sich automatisch die lokale Kontrollseite mit eingebetteter App.

DIREKTE ADRESSE
http://localhost:3000

WICHTIG
- Node.js LTS muss installiert sein.
- Das schwarze Startfenster während der Nutzung geöffnet lassen.
- Zum Beenden Strg+C drücken oder das Startfenster schließen.
- Trainingsdaten werden lokal im verwendeten Browser gespeichert.

ALTERNATIVEN
- START_NEBURION_WINDOWS.bat: öffnet die App direkt.
- START_NEBURION_ENTWICKLUNG.bat: Entwicklungsmodus für Codeänderungen.
- NEBURION_XV73_LOKALE_VORSCHAU.html: Kontrollseite; benötigt den laufenden lokalen Server.

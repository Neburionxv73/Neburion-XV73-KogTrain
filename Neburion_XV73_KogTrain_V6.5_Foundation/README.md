# Neburion XV73 — Kognitive Trainingsplattform V6.5

## Status
Version 6.5 ist der verbindliche Neustart- und Fortsetzungsstand der kognitiven Trainingsplattform.

## Ziel
Eine modulare, barrierearme und nachvollziehbar geprüfte Trainingsplattform für kognitive Übungen in mehreren Trainingswelten. Die Plattform ist ein Trainings- und Lernsystem und stellt keine medizinische Diagnose oder Behandlung dar.

## Trainingswelten
- Memory Lab
- Attention Lab
- Logic Lab
- Language Lab
- Visual Lab

## V6.5 Leitprinzipien
- Raptor Delta V9.7 als verbindlicher Produktions- und QA-Standard
- NO EVIDENCE → NO PASS → NO RELEASE
- Builder und Reviewer technisch getrennt
- Responsive: Desktop designed, Tablet recomposed, Smartphone reprioritized
- Accessibility, Performance, SEO und Security als blockierende Gates
- lokale/offline-freundliche Architektur, wo technisch sinnvoll
- transparente adaptive Empfehlungen statt Black-Box-Bewertungen
- Trainingsdaten standardmäßig lokal im Browser, sofern keine explizite Serverfunktion vorgesehen ist

## Projektstruktur
- `src/` — Plattformcode
- `public/` — statische Assets
- `docs/` — Spezifikation und Architektur
- `qa/` — QA- und Gate-Nachweise
- `release/` — Release-Dokumentation
- `scripts/` — Validierungs- und Build-Skripte

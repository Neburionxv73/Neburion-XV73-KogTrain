# Manueller Geräteprüfplan für Version 4.0

## Geräteklassen

- Windows Desktop: Chrome und Edge
- Notebook bei 1366 × 768
- Android Smartphone im Hoch- und Querformat
- Android Tablet im Hoch- und Querformat
- iPhone/iPad, sofern verfügbar

## Kritische Nutzerwege

1. Onboarding vollständig abschließen.
2. Schnelltraining starten und beenden.
3. Je eine Aufgabe aus Memory, Attention, Logic, Language und Visual absolvieren.
4. Feedback, Coach-Empfehlung und Session-Abschluss lesen.
5. Fortschritt und Meilensteine prüfen.
6. Profil speichern, Backup exportieren und wieder importieren.
7. PWA installieren, Verbindung trennen und besuchte Seiten offline öffnen.
8. Fokusansicht, Tastaturbedienung und reduzierte Bewegung kontrollieren.

## Abnahmekriterien

- keine überlappenden oder abgeschnittenen Texte
- Touch-Ziele ausreichend groß
- alle Buttons und Links erreichbar
- keine beschämenden oder defizitorientierten Coach-Texte
- Trainingsergebnisse bleiben nach Neuladen erhalten
- Offline-Fallback funktioniert ohne Browserfehler
